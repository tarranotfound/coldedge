# coldedge

Dark blue + white Sway theme with a minimal Waybar and wlclock setup.

- Waybar: top status bar
- wlclock: bottom-right clock layer
- Palette: deep blue, icy blue, white

## Components

coldedge keeps the bar, clock, Sway snippets, and shared palette separate so each piece can be adjusted independently.

## Design

The interface favors compact text, straight edges, and a restrained blue-and-white palette.
